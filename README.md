# Prasharya Karmacharya — Portfolio

## Files
- index.html — main website
- style.css — design and responsive styling
- script.js — small JavaScript functionality
- images/ — place your photos/project images here

## Customize
1. Edit the text in `index.html`.
2. Replace the placeholder social links (`href="#"`) with your real URLs.
3. To use a profile photo, replace the `PK` avatar with an image.
4. Upload all files to your GitHub Pages repository.

## Free hosting
This site is static and can be hosted for free with GitHub Pages.
